lite-oc, 더블클릭 한 번으로 켜지는 오케스트레이션 서버

전시장에서 사람, 로봇, 태블릿, AI 동반자를 엮어 주던 서버가 있습니다. 잘 돌지만 띄우려면 데이터베이스, 메시지 큐, 저장소, 관측 도구까지 줄줄이 필요했습니다. 교육용으로 누구나 자기 노트북에서 켤 수 있게, 같은 흐름을 파일 하나로 다시 만들었습니다.

AI 는 이렇게 돈다

에이전트는 Eino 로 만든 단순한 반복입니다. 모델이 도구를 부르면 실행하고, 결과를 모델에 돌려주고, 더 부를 게 없으면 답합니다. 프롬프트에 값을 끼워 넣지 않고, 필요한 데이터는 모델이 도구로 직접 꺼내 갑니다.

  1. 질문
  2. 모델 호출
  3. 도구 실행
  4. 결과를 모델에
  5. 답변

모델은 어드민에서 고릅니다. 로컬 Ollama, OpenAI 호환 API, Claude, 사내 게이트웨이 중 하나를 골라 저장하면 재시작 없이 다음 호출부터 바뀝니다. 답변은 SSE 로 토큰이 나오는 대로 흘려보냅니다.
