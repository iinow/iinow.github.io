How it judges — a change is breaking when a client would stop working without being updated.

  • Breaking: endpoint or response code removed, required parameter added, parameter turned from optional into required, type change in a request or response schema, required field added to a request body, response field removed, enum value removed from a request, enum value added to a response.
  • Safe: new endpoint, optional parameter or field added, response field added, enum value added to a request, parameter relaxed to optional, deprecated flag.
  • $ref is resolved inside the document, and parameters are paired by in and name. For content, application/json is preferred.
  • Nothing is sent anywhere. Files are read in the browser only.
