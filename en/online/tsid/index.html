Layout — a TSID is one 64-bit integer. The top 42 bits count milliseconds since 2020-01-01T00:00:00Z; the remaining 22 bits are split into a node ID and a counter. With 10 node bits the counter gets 12, so one millisecond holds 4096 IDs in order. This page gives the counter whatever the node leaves and moves to the next millisecond when the counter overflows.

  • Crockford Base32 writes those 64 bits in 13 characters. I and L read as 1, O as 0, and case does not matter.
  • Decoding splits node and counter with the node bits selected above. For a TSID made with another setting, match the node bits to get those parts right.
  • Int64 is the same bits read as a signed integer. When the top bit is 1 it shows as a negative number.
  • Nothing you type leaves this browser, and a reload clears anything you generated.
